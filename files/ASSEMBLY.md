## Part 2 — Geometric mold

```
   mold_half_a_pins          mold_half_b_sprue
   ┌─────────────┐   pins    ┌─────────────┐
   │  cavity ½   │ ═══════►  │  cavity ½   │
   │             │           │   + sprue   │
   └─────────────┘           └─────────────┘
              │ close & optional pour
              ▼
        cast frustum  ↔  compare to mold_master_frustum
```

No fasteners required. Mold halves locate with printed alignment pins.
