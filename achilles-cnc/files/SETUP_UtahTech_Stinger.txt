## Fusion 360 steps (Stinger)

1. New Design → Import SVG or DXF (units **inches**, insert on XY).
2. Scale check: sketch should read **~32" × 8.5"**.
3. Manufacture workspace → New Setup  
   - Orientation: Z up, X along board length  
   - Stock: your maple deck (or a scrap the same thickness)  
   - Origin: bottom-left of outline (match how you zero the Stinger)
4. **Toolpath A — SHADE** (select SHADE curves)  
   - 60° V-bit **or** 1/8" ball nose  
   - Depth: **0.04–0.08"** (1–2 mm) — light optical shade  
   - Climb mill, moderate feed; test on scrap first
5. **Toolpath B — LOGO** (select LOGO curves)  
   - 60° V-bit preferred for crisp emblem  
   - Depth: **0.10–0.20"** (2.5–5 mm) — deep carved look (OK to go deep as requested)  
   - Keep above truck holes if deck is already drilled
6. Post process → **WinCNC** post → save `.tap`
7. On Stinger PC: open WinCNC → load `.tap` → set zeros → dry run / frame → cut

## Bits & safety

- Maple holds detail well; sharp bit, clear chips  
- Vacuum / clamps — deck must not move  
- Complete Utah Tech Makerspace CNC training before booking the Stinger  
- Always scrap-test depth/feeds

## Design

Full-board vertical wave shade + deep center Spartan medallion (Greek key ring, laurel, helmet) + ACHILLES.
