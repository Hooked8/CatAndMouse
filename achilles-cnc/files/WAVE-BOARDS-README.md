# Achilles Wave / Optical Boards — CNC pack

Five full-deck underside designs (813 × 210 mm). Each file is **one job**:

1. Layer `SHADE` — wavy / ripple / diamond optical engraving across the whole board (light pass)
2. Layer `LOGO` — deeper logo + ACHILLES (second pass or same file with higher power / deeper depth)

## Files

| File | Design |
|------|--------|
| 14-board-spartan-waves | Spartan helmet + Greek key + vertical waves |
| 15-board-eye-waves | Eye of Horus + vertical waves |
| 16-board-laurel-waves | Open laurel + vertical waves |
| 17-board-pinecone-ripples | Pinecone labyrinth + concentric ripples |
| 18-board-lambda-diamond | Lambda in laurel + diamond hatch |

## Machine tips

- Engrave **underside** only
- Delete `#guides` before cutting
- Shade: shallow ball-nose or fine V-bit, light depth (~0.3–0.8 mm)
- Logo: deeper V-bit pass (~1–2 mm) or higher laser power
- Scrap-test maple first
