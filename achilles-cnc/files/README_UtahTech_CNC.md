## Board size
- **Width: 8.5 inches**
- Length: 32 inches
- Center crest + dense all-over icon pattern (deep V-carve strokes)

## Deep carve settings (match your reference look)
- Bit: **60° V-bit** preferred
- Flat depth limit: **1/8"–3/16" (0.125–0.1875")**
- Test on scrap maple first, then full deck
- Optional: wipe dark stain into recesses after carving for bottle-style contrast
