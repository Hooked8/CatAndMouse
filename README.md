# ACHILLES Patellar Strap Lookbook

Interactive product design for a lightweight patellar tendon strap (not a brace) with five snap-on fashion shells.

## Run locally

```bash
npm install
npm run dev
```

## System

- **Chassis** — charcoal mesh band, moisture-wicking liner, silicone grip dots, soft silicone pressure pad, four snap posts, low-bulk closure
- **Shells** — Prism Labyrinth, Violet Marble, Spartan Surge, Horus Agate, Electric A
