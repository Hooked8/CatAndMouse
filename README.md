# Silver Reef: The Prospector’s Field Guide

Educational field-guide website for the Silver Reef Mining District, Washington County, Utah.

## Run locally

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000`.

## Content standards

- Real photographs only (UGS GeoSights, Wikimedia Commons, GeoDIL/UND, HABS, museums).
- Silver Reef locality images are labeled as such.
- Same-species reference specimens from other Utah localities are labeled **Reference** and never claimed as Silver Reef finds.
- Geology follows Utah Geological Survey and Utah Geological Association sources.

## Stack

Static HTML, CSS, and JavaScript. No build step.
